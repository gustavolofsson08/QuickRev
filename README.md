# QuickRev UF

Hemsidan för QuickRev UF, ett UF-företag från Elof Lindälvs gymnasium i Kungsbacka. Vi säljer NFC-skyltar som tar kunden direkt till företagets Google-recension.

Sidan är helt statisk (HTML, CSS och JavaScript) och behöver ingen byggprocess.

- Kontaktuppgifter, formuläradress och statistik ställs in i `config.js`.
- Bilder, ikoner och typsnitt ligger i `public/`.
